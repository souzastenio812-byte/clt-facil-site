# CLT Fácil

Site estático mobile-first com seis calculadoras trabalhistas.

## Calculadoras
- Salário líquido 2026
- Horas extras
- Férias
- 13º salário
- FGTS
- Rescisão

## Publicação
O projeto é estático e pode ser publicado diretamente na Vercel.

## AdSense
A publicidade real está desativada. Adicione o código e o ads.txt somente após receber o Publisher ID oficial.

## Aviso
Os resultados são estimativas educacionais. Convenções coletivas e situações individuais podem alterar os valores.
